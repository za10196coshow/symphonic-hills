# シンフォニックヒルズ GitHub Pages版

このフォルダの中身をGitHubリポジトリのルートへアップロードしてください。

## 公開設定

1. GitHubのリポジトリで `Settings` を開く
2. 左側の `Pages` を開く
3. `Source` を `Deploy from a branch` にする
4. Branchを `main`、フォルダを `/(root)` にする
5. `Save` を押す

数分後、次の形式のURLで公開されます。

`https://ユーザー名.github.io/リポジトリ名/`

## 更新方法

文章は `index.html`、デザインは `style.css`、画像は `images` フォルダにあります。変更したファイルをGitHubへ再度アップロードすると、自動的に公開サイトへ反映されます。

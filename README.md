# シンフォニックヒルズ GitHub Pages版

このフォルダ内のファイルを、GitHubリポジトリのルートへアップロードしてください。

## 動画の追加

生成した動画を次の場所へ配置します。

`videos/symphonic-hills-pr.mp4`

推奨形式：MP4／H.264／16:9。動画を置く前はポスター画像が表示されます。

## GitHub Pagesの設定

リポジトリの `Settings` → `Pages` で、Sourceを `Deploy from a branch`、Branchを `main`、フォルダを `/(root)` にして保存してください。
